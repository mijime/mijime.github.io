# saiflow

人生のお金の流れを年単位で試算するアプリです。金額の単位はすべて **万円** です。

- Web: 年齢・収入・生活費・住宅・教育・投資・年金をイベントとして並べ、資産推移とアドバイスを表示
- かんたん入力（ADV）: 1年ずつ選択肢を選ぶだけで、未来のイベントを自動入力
- CLI: 同じDSLを読み込み、表・CSV・JSON・リスク試算を出力

## CLI

```bash
# サンプルを10年分
pnpm sim --years 10

# 年齢・期間・シナリオを指定
pnpm sim --age 40 --years 30 --no-advice
pnpm sim --scenario 早期リタイア

# ファイル入力
pnpm sim path/to/plan.txt --age 35 --years 50

# CSV / JSON
pnpm sim --csv --years 10 > plan.csv
pnpm sim --all --json > plans.json

# モンテカルロのリスク試算（投資リターン・大病・介護）
pnpm sim --trials 1000 --seed 42
```

主なオプション:

| オプション           | 説明                                |
| -------------------- | ----------------------------------- |
| `-a, --age <n>`      | 現在の年齢（default: 35）           |
| `-y, --years <n>`    | シミュレーション年数（default: 50） |
| `-s, --scenario <n>` | シナリオ名または1始まりの番号       |
| `--all`              | すべてのシナリオ                    |
| `--csv` / `--json`   | 出力形式                            |
| `--no-drawdown`      | 現金不足時に投資を自動取り崩さない  |
| `--trials <n>`       | リスク試算の回数（0で無効）         |
| `--seed <n>`         | リスク試算の乱数シード              |
| `--no-advice`        | アドバイスを非表示                  |

`pnpm sim --help` にすべてのオプションがあります。

## 計算の考え方

- **現金収支**: 現金の増減だけを収入・支出として集計します。借入・積立・運用益・資産取り崩しは「振替」として収支から除外します。
- **総資産**: 現金・投資・住宅などの資産と、借入などの負債を合算した純資産です。
- **自動取り崩し**: 現金がマイナスになったとき、NISA → その他の投資 → iDeCo（60歳以降）の順で売却して補います。ヘッダーのチェックでオフにできます。
- **税金・社会保険**: 年収・給与・賞与・副業などの給与収入から、所得税・住民税・社会保険料を実効負担率で概算します（〜300万15%、〜500万18%、〜700万20%、〜1000万22%、〜1500万26%、それ以上31%）。初期現金・臨時収入・年金・投資の売却は対象外です。ヘッダーの「税・社保（概算）」でOFF、CLIは `--no-tax` で無効化できます。明示的な「税金」「所得税」「住民税」「社会保険」イベントがある場合は自動計算しません。
- **退職後**: 生活費は現役時代の85%を目安にし、年金は65歳から収入として計上します。
- **リスク試算**: 投資リターンを年ごとに±8%で振り、大病・介護を確率的に発生させて、最終資産のP10/P50/P90と資産枯渇確率を出します。

## モデルの割り切り

- 税金・社会保険は実効負担率による概算で、扶養・控除・自治体差・正確な料率は考慮していません。インフレは考慮していません。
- 住宅は取得価格のまま（減価償却なし）で、売却・住み替えは考慮しません。
- 年金は固定額で、繰上げ・繰下げ・在職老齢年金は考慮しません。
- 大病・介護の確率は年齢別の近似モデルで、実際の罹患率・費用を保証するものではありません。
- 投資リターンは年ごとの正規分布近似で、実際の市場の連続性・暴落・為替は考慮していません。
- 結果は概算であり、投資助言ではありません。

## 開発

```bash
pnpm --filter @mijime/saiflow dev
pnpm --filter @mijime/saiflow test
pnpm --filter @mijime/saiflow check
pnpm --filter @mijime/saiflow build
```

WebのADV入力は、オンボーディングの「1年ずつ選んで作る（ADV）」、または保存一覧の「ADVで作る」から開始できます。

既存プランを開いた状態でADVタブを開くと、「このプランに未来のイベントを追加」を選べます。既存のイベントは残したまま、子ども・教育・車・大病/介護に加えて、住宅購入・NISA積立・退職年齢の変更も追記できます。住宅購入時は既存の家賃を購入年前年で停止し、退職時は既存の給与収入を指定年齢で停止します。NISAは既存の積立と重複する場合があるため、選択後にGUI/DSLで確認してください。
