# 2〜3歳向け知育アプリ「おてて (otete)」— 目指すミッション・期待する効果・設計根拠

この文書は「おてて」(otete) の体験設計と難易度モデルを、2〜3歳児の発達心理学と「触って遊ぶおもちゃ設計（Tactile Toy Design）」に沿って定義したものです。

---

## 1. 目指すミッション（Mission）

> **「『正解を当てるクイズ』を捨て、指先ひとつで世界がよろこぶ『生きたおもちゃ箱』をつくる」**

2〜3歳はエリクソンの発達段階で**「自律性 対 恥・疑惑」**（いわゆるイヤイヤ期・自分でやりたい期）にあたります。
この時期の子どもにとって、画面から一方的に「〇〇はどれ？」と試され、間違えると「ブッ（もういちど）」と言われるドリル型アプリは、内発的な動機づけを生まないばかりか「試されているストレス」になります。

**「おてて」のミッションは、文字ゼロ・説明ゼロ・失敗ゼロの「生きたおもちゃ」を通じて、子どもが自ら手を伸ばし、「自分が動かしたから世界が変わった！」「くまさんが喜んでくれた！」という主体性（エージェンシー）と親子の会話を引き出すことです。**

---

## 2. 期待する効果（Expected Effects）

### ① 主体性（エージェンシー）と自己効力感の獲得

- **即時・多感覚の因果関係**: 「りんごを口に運ぶと大きな口を開けて『あむっ！』と食べて喜ぶ」「泡をゴシゴシこすると下から動物が『ばあっ！』と現れる」という手応えにより、自分が世界に働きかけて変化を起こせる感覚（自己効力感）を育みます。
- **エラーレス（失敗ゼロ）設計**: まだ狙いが定まらない2歳児が違う場所を触ったり、途中で指を離したりしても、否定的なブザーや進行リセットを行いません。「ぽよん♪」と優しく跳ね返る・食べたもの全部を「おいしいね！」と肯定することで、安心して試行錯誤できます。

### ② 微細運動（指先の巧緻性）と目と手の協応の発達

- 単なる「画面をポチポチ叩くだけのタップ」にとどまらず、発達段階に応じた多様な指先運動を自然に引き出します：
  - **つまんで運ぶ（ドラッグ＆ドロップ）**: 「もぐもぐ」「すぽっ！」
  - **面をゴシゴシこする（スクラッチ・往復運動）**: 「あわあわ・ばあっ！」
  - **道に沿って指を滑らせる（前書字ストローク・運筆）**: 「ぽっぽー！」
  - **自由に描く・スタンプを押す（表現運動）**: 「おえかき」
- 2歳前半でドラッグがまだ難しい子のため、**「タップだけでも気持ちよく飛んでいく／はまる」アシスト**を全画面に備えています。

### ③ 「生きた文脈（ごっこ遊び）」での語彙・色・形・数・大小の獲得

- フラッシュカードの機械的暗記ではなく、**見立て・ごっこ遊びの文脈**の中で概念を吸収します：
  - **名詞と形容詞（色・味）**: 「くまさんに『あかい りんご』をあげる」
  - **数（1対1対応と唱数）**: 「『2こ ちょうだい』に対して1つずつ食べさせながら『いち！』『に！』と数える」
  - **空間認識・形・大小**: 「まる・さんかく・しかく・おおきい・ちいさいの穴にピースが磁石のように『スポッ！』と吸い込まれる」

### ④ 親子のコミュニケーション誘発（親の声・実写写真）

- 親の声（Parentese）や家族が撮った実写写真は、乳幼児の注意と語彙定着を強く促します（Kuhl, 2004）。
- おうちの人が録音した声や追加した写真が「もぐもぐ」「あわあわ」「ずかん」にそのまま登場し、横で見守る親が「テスト監督」ではなく「遊び仲間」として声をかけたくなる設計にしています。

## 3. 5つの主力おもちゃ（プレイワールド）と発達根拠

| おもちゃ        | 遊びの体験                                                                                                     | 育まれる力・難易度の上昇軸（上限なし）                                                                                               |
| --------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **🍎 もぐもぐ** | 目線が指を追う動物（くま・うさぎ・ぱんだ・かえる）に食べ物をあーん！と食べさせるごっこ遊び                     | **語彙・色・1対1対応の数**: 2択の食べ物 → 3〜4択 → 「あかいもの ちょうだい（色属性）」 → 「2こ・3こ ちょうだい（数と1対1対応）」     |
| **🫧 あわあわ** | 泡の山を指でゴシゴシこすって洗い流し、隠れている動物や乗り物を「いないいない…ばあっ！」と見つける              | **微細運動（こする）・対象の永続性・語彙**: 鳴き声や音のヒントから予測し、自分の指で面を消して発見する喜び                           |
| **🧩 すぽっ！** | 木のボードの穴に「かたち」「いろ」「おおきい・ちいさい」のピースをスポッとはめる型はめパズル                   | **形・色・大小比較・目と手の協応**: 2ピースから始まり、3〜4ピースへ増加。磁石のような吸着とタップアシスト付き                        |
| **🚂 ぽっぽー** | 指でなぞった場所に虹の線路がかかり、きかんしゃや消防車がイチゴや星を集めながら駅まで走る                       | **運筆（前書字ストローク）**: 縦横の直線 → ゆるいカーブ → なみ線 → ぎざぎざ → 円・うずまき。途中で指を離しても進行が消えない安心設計 |
| **🎨 おえかき** | 触れるだけで木琴（ペンタトニック音階）が鳴り、にじ・色クレヨン・しゃぼん玉・星・動物スタンプで描けるキャンバス | **感覚運動・色彩・音感・自己表現**: どの順番で触っても心地よい和音になる音階設計                                                     |

さらに下部シェルフから **📖 ずかん**（おうちの声・写真つきの絵じてん）、**🔢 かず**（3Dオブジェクトの数え・比較）、**📷 かがみ**（カメラを使った全身あそび）、**🖼️ さくひん**（保存したおえかきギャラリー）へいつでもアクセスできます。
