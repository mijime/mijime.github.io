# madories 許容応力度計算 対応 調査・設計

日付: 2026-09-15
ステータス: **調査・設計のみ（コード変更なし）**

## 1. 背景 / 現状

madories は現在「簡易耐震診断」を提供している。実体は壁量・四分割・偏心率・上下バランスの
目安判定であり、**許容応力度計算（令第82条以下の構造計算）ではない**。

| 現行機能       | 実装                                                          | 内容                                                       | 限界                                     |
| -------------- | ------------------------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------- |
| 壁量           | `src/floor/wall-quantity.ts`                                  | 面積 × `NEED_PER_M2 = 0.45` の一律必要壁量                 | 地域・用途・階・材料・壁倍率・開口を無視 |
| 方向別バランス | `src/floor/structure-metrics.ts` `computeBalanceRatio`        | h/v 壁長の比 ≥ 0.5                                         | 壁倍率なし。長さ＝耐力とみなす           |
| 偏心率         | `src/floor/structure-metrics.ts` `computeEccentricity`        | 剛心（壁長加重）と重心（床面積）の距離 / 平面スパン < 0.15 | 剛性を壁長で近似。弾力半径を使わない     |
| 外周連続性     | `src/floor/structure-metrics.ts` `computePerimeterContinuity` | 外周の `solid` 率 ≥ 0.5                                    | 開口幅・壁倍率なし                       |
| 上下バランス   | `src/floor/wall-quantity.ts` `computeInterFloorWallBalance`   | 下階壁長 ≥ 上階壁長                                        | 層重量・C0 なし                          |
| 四分割         | `src/floor/quadrant-balance.ts`                               | 各象限に両方向の `solid` があるか                          | 令46条の四分割法の簡易版                 |
| 柱・通し柱     | `src/floor/shear-walls.ts`                                    | 壁ラン端点を柱とみなす / 階間の一致                        | 柱寸法・軸力なし                         |

現行の壁種別（`src/types.ts`）は `solid` のみを耐力壁とし（`STRUCTURAL_WALL_TYPES`）、
`window_full` / `window_center` / `solid_thin` は開口としてランを分断する。壁倍率・開口低減の概念はない。

単位系は `src/units.ts`: 1 cell = 455mm（1/2間）、`SHEAR_STABLE_MIN_MM = 1820`。

`src/components/shear-diagnostic/index.tsx` の免責文:

> 簡易目安です。実際の構造・耐震計算は建築士/構造設計者に相談してください。

## 2. 目的と範囲

- **目的**: 許容応力度計算を madories に載せる場合に「何が必要か」を整理し、データモデル案と計算仕様を確定させる。
- **対象（第一候補）**: 木造在来軸組工法・2階建以下・ルート1またはルート2相当。
- **範囲外**: コード実装、法適合の断定、鉄骨造/RC造、基礎・地盤、保有水平耐力計算（ルート3）、時刻歴応答解析。

## 3. 許容応力度計算の全体像

```
[入力]                    [モデル化]              [解析]                 [検定]
建物・地域情報      →   荷重の集計        →   応力の計算        →   断面検定
荷重条件                構造グリッド            鉛直: 梁 M,Q       曲げ σb = M/Z
材料・断面              柱・梁・耐力壁          水平: 壁 Qw, 柱 M   せん断 τ = Q/A
                        剛床仮定                階: 層せん断 Q      圧縮 σc = N/A（座屈）
                                                                →  変形・剛性率・偏心率
```

ルートとの関係（令第82条各号）:

- **ルート1**: 壁量計算（令46条・令82条の4相当）＋仕様規定。応力解析をしない。
- **ルート2**: ルート1 ＋ 令82条の6（剛性率・偏心率）。中規模まで。
- **ルート3**: 令82条の2〜6 すべて。保有水平耐力まで。

許容応力度計算は「長期・短期の各応力 ≤ 各許容応力度」の検定を、部材・接合部単位で行う。
madories が目指すなら **ルート1の延長としてルート2の一部（剛性率・偏心率）まで** が現実的な上限。

## 4. 必要な入力データ

### 4.1 建物・地域情報

| 項目                 | 出典               | 現状         | 備考                           |
| -------------------- | ------------------ | ------------ | ------------------------------ |
| 用途（住宅/事務所…） | 令85条             | なし         | 積載荷重に影響                 |
| 地域（都道府県）     | 令86条・令87条ほか | なし         | 積雪・基準風速・地震地域係数 Z |
| 多雪区域判定         | 令86条             | なし         | 積雪荷重の割増                 |
| 階数・階高・軒高     | —                  | **階高なし** | 地震力・座屈・層間変形角       |
| 構造種別・工法       | —                  | なし         | 木造在来/枠組、鉄骨…           |
| 屋根形状・勾配       | 令86条             | なし         | 積雪低減                       |

### 4.2 荷重・外力

| 荷重           | 式（概略）                           | 出典           | 現状                          |
| -------------- | ------------------------------------ | -------------- | ----------------------------- |
| 固定荷重 G     | 部材・仕上げの自重を集計             | 令84条         | **なし**（面積×一律係数のみ） |
| 積載荷重 P     | 用途・部位別の単位荷重 × 床面積      | 令85条         | なし                          |
| 積雪荷重 S     | 垂直積雪量 × 単位荷重 × 屋根勾配低減 | 令86条         | なし                          |
| 風圧力 W       | `q = 0.6 · E · V0²`、`E = Er² · Gf`  | 令87条         | なし                          |
| 地震力 Q       | `Qi = Ci · Wi`                       | 令88条         | なし                          |
| 層せん断力係数 | `Ci = Z · Rt · Ai · C0`              | 令88条2項・3項 | なし                          |

- `Wi`: 各層の固定荷重＋積載荷重（地震用）＋積雪。
- `C0`: 標準せん断力係数（1次設計で 0.2 以上）。木造は告示で割増があるため実装時に一次資料で確認。
- `Z`: 地震地域係数（1.0〜0.7）。
- `Rt`: 振動特性係数（令88条2項、告示）。
- `Ai`: 層せん断力係数分布（令88条3項、`Ai = 1 + (1/√αi − αi)·2T/(1+3T)`）。
- 風圧力の `Er`（高さ分布）・`Gf`（ガスト影響係数）は告示（要確認）。

### 4.3 構造モデル

| 項目                 | 現状                             | 必要な理由             |
| -------------------- | -------------------------------- | ---------------------- |
| 通り芯・スパン       | **なし**（壁のセル座標のみ）     | 梁の応力・柱の負担範囲 |
| 柱（位置・寸法）     | 壁ラン端点を疑似柱として検出のみ | 軸力・座屈・接合部     |
| 梁（位置・寸法）     | なし                             | 曲げ・せん断・たわみ   |
| 耐力壁（種別・倍率） | `solid` のみ、倍率なし           | 層せん断力の負担       |
| 開口（幅・位置）     | `window_*` でラン分断のみ        | 壁倍率の開口低減       |
| 床・屋根の剛床仮定   | なし                             | 水平力の分配           |
| 接合部               | なし                             | 許容耐力の検定         |

### 4.4 断面・材料

| 項目                  | 式                                      | 現状 |
| --------------------- | --------------------------------------- | ---- |
| 断面性能 `A, I, Z, i` | 矩形 `A=bh, I=bh³/12, Z=bh²/6, i=h/√12` | なし |
| 基準強度 `F`          | 樹種・等級（令89条）                    | なし |
| 長期許容応力度        | 木材は低減あり（告示、要確認）          | なし |
| 短期許容応力度        | 原則 長期 × 割増（1.5 など）            | なし |
| ヤング係数 `E`        | 樹種・等級                              | なし |
| 座屈・有効長さ        | `λ = lk / i`                            | なし |

### 4.5 検定・変形条件

| 項目       | 基準                                  | 現状                        |
| ---------- | ------------------------------------- | --------------------------- |
| 曲げ       | `σb = M/Z ≤ fb`                       | なし                        |
| せん断     | `τ = Q/A`（または `Q·S/(I·b)`）`≤ fs` | なし                        |
| 圧縮       | `σc = N/A ≤ fc`（座屈低減）           | なし                        |
| 引張       | `σt = N/A ≤ ft`                       | なし                        |
| 接合部     | 許容耐力（告示）                      | なし                        |
| 剛性率     | `Rs = rs / rs平均 ≥ 0.6`              | なし                        |
| 偏心率     | `Fe ≤ 0.3`                            | 簡易近似のみ（0.15/スパン） |
| 層間変形角 | `≤ 1/200`                             | なし                        |

## 5. 現状データモデルとのギャップ

`src/types.ts` の現行型:

```typescript
interface FloorPlan {
  id;
  name;
  width;
  height;
  originX;
  originY;
  cells: Cell[]; // floorType, item, roomName
  hWalls: WallType[]; // "none" | "solid" | "solid_thin" | "window_full" | "window_center"
  vWalls: WallType[];
}
interface Building {
  cellSize: number;
  floors: FloorPlan[];
}
```

不足しているもの（優先順）:

1. **建物条件**（用途・地域・階数・階高・構造種別）— `Building` に無い。
2. **荷重条件**（積載・積雪・風・地震の前提）— 型が無い。
3. **材料・断面**（樹種・等級・部材寸法）— 型が無い。
4. **耐力壁の倍率・開口低減** — `WallType` が種別のみ。
5. **柱・梁の軸組** — 壁ラン端点からの推定のみで、独立した型が無い。
6. **階高** — `cellSize`（平面）はあるが鉛直寸法が無い。

結論: **現行の型のままでは許容応力度計算は成立しない**。少なくとも「建物条件・荷重条件・
材料断面・耐力壁倍率」の4グループを追加する必要がある。

## 6. データモデル案（実装はしない）

```typescript
// 建物条件（Building に追加）
interface BuildingConditions {
  use: "residential" | "office" | "shop" | ...;   // 令85条の用途区分
  region: string;                                  // 都道府県
  snowZone: boolean;                               // 多雪区域
  groundSnowDepthCm: number;                       // 垂直積雪量
  referenceWindSpeed: number;                      // V0 (m/s)
  seismicZoneFactor: number;                       // Z
  structure: "wood_post_beam" | "wood_frame" | ...;
  storyHeightMm: number[];                         // 階ごとの階高
}

// 耐力壁の耐力（壁倍率）
interface ShearWallSpec {
  kind: "h" | "v";
  x: number; y: number; cells: number;
  multiplier: number;                              // 壁倍率（告示）
  openingReduction: number;                        // 開口低減率
  // 耐力 = 壁倍率 × 開口低減 × 長さ(m) × 1.96 kN/m（倍率1あたり）
}

// 部材（柱・梁）
interface Member {
  id: string;
  role: "column" | "beam";
  startVertex: [number, number];                   // 通り芯頂点
  endVertex: [number, number];
  sectionMm: { b: number; h: number };             // 矩形断面（木造）
  material: { species: string; grade: string };    // 令89条の基準強度に写像
}

// 荷重条件（Building に追加）
interface LoadConditions {
  floorUnitLoads: Record<FloorType, number>;       // 固定+積載 (N/m²)
  roofUnitLoad: number;
  wallUnitLoadPerM2: number;                       // 外壁・内壁
  appliedSeismicC0: number;                        // 採用 C0
}
```

設計方針:

- 既存の `hWalls`/`vWalls` は**残す**。耐力壁は「エッジ配列から検出したラン＋倍率」として別レイヤに持つ。
- 柱・梁は「頂点（通り芯）」を一級データに昇格させる（現行 `detectStructuralColumnVertices` の延長）。
- 荷重は `FloorType` と部位（屋根/床/壁）の単位荷重テーブルから集計。既存の `floorType` を活用する。
- 保存形式は新規フィールドを任意（optional）にし、未入力なら現行の簡易診断のみ提供する（段階移行）。

## 7. 計算仕様（段階）

### 7.1 荷重集計

1. 床面積・屋根面積・外周長を、既存の `computeWallBounds` / セル走査から算出。
2. `固定荷重 = Σ(部位面積 × 単位荷重)`、`積載荷重 = Σ(床面積 × 用途別単位荷重)`。
3. `積雪荷重 = 垂直積雪量 × 単位荷重 × 屋根勾配係数`（多雪区域は割増）。
4. `地震力 Qi = Ci · Wi`、`Ci = Z · Rt · Ai · C0`（令88条）。
5. `風圧力` は耐力壁の検定ではなく、必要壁量系の検討に使う（令87条）。

### 7.2 応力解析

- **ルート1相当（最小）**: 応力解析せず、`Qi` を耐力壁で負担できるか + 四分割 + 剛性率/偏心率。
- **ルート2相当（推奨）**: 鉛直は単純梁、水平は剛床仮定で耐力壁へ分配し、柱は負担せん断から曲げを算定。
- **立体解析**: 範囲外（Phase 5 以降の将来課題）。

木造在来の場合、許容応力度計算は通常「剛性を考慮した立体解析」または「略算」。
madories の格子モデルとは整合しないため、まずは**耐力壁＋柱軸力の略算**に留めるのが妥当。

### 7.3 断面検定

```
曲げ:   σb = M / Z ≤ fb
せん断: τ  = κ·Q / A ≤ fs        （κ: 形状係数、矩形1.5）
圧縮:   σc = N / A ≤ fc          （座屈: λ = lk/i による低減）
引張:   σt = N / A ≤ ft
```

`fb, fs, fc, ft` は令89条の基準強度 F と告示の低減・割増から求める（**一次資料で要確認**）。

### 7.4 変形・剛性率・偏心率

```
層間変形角 = δ / h ≤ 1/200
剛性率     Rs = rs / rs平均 ≥ 0.6
偏心率     Fe = （剛心と重心の距離）/（弾力半径） ≤ 0.3
```

現行 `computeEccentricity` は「距離 / 平面スパン」の簡易指標。弾力半径を使う Fe に置き換えるには
各耐力壁の剛性（倍率・長さ・開口）が必要。

## 9. 法規上の注意 / 免責

- 許容応力度計算は建築基準法上の**構造計算**であり、最終的な確認は**建築士（構造設計）**が行う必要がある。
- ルートの誤用（ルート1で足りる建物にルート2を適用、逆にルート2が必要な建物をルート1で判定）は
  違法・危険につながる。アプリは**補助ツール**であり、適合性を断定してはならない。
- 現行の免責文（簡易目安・建築士への相談）は全 Phase で維持する。
- 数値（C0、壁倍率、低減率、許容応力度）は**必ず令・告示の一次資料から実装時に確定**する。
