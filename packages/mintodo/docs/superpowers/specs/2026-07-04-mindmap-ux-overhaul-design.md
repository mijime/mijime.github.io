# mintodo UX 全面見直し — Phase 1: マインドマップ核心部

日付: 2026-07-04

## 背景

現行のマインドマップは放射状レイアウトで読みにくく、ノード入力が EditModal 依存で重く、パン/ズーム操作(右/中クリックドラッグ)が直感的でない。2フェーズで UX を刷新する。

- **Phase 1(本仕様)**: マインドマップの表示・入力・操作感
- **Phase 2(別仕様)**: ツールバー、ビュー切替、kanban/gantt/text を含む全体シェル

## 1. 横方向ツリーレイアウト

- `src/layout/radial.ts` を `src/layout/tree.ts`(横方向ツリー)に置き換える。
- ルートを左端に固定し、子を右方向へ展開。各サブツリーの必要高さを再帰計算し、親を子群の垂直中央に配置する純関数 `layoutTree(nodes, options): Record<id, {x, y}>`。
- ノード座標は毎回レイアウト計算で決定(完全自動配置)。手動座標は持たない。
- `MindNode` に `collapsed: boolean` を追加。折りたたみ中のノードは:
  - 子孫を非表示・レイアウト対象外とする
  - カードに「+N」バッジ(非表示の子孫数)を表示
  - トグル: ノードの開閉ボタンクリック、またはキーボード `C`
- 接続線(`ConnectionLines.tsx`)は水平ベジェ曲線(親カード右端中央 → 子カード左端中央)に変更。完了ノードへの破線スタイルは維持。

## 2. インライン編集

- **新規作成**: Tab(選択ノードの子)/ Enter(兄弟)で空ノードをレイアウト上のその位置に生成し、カード内 `<input>` に即フォーカス。
  - Enter: 確定(テキスト空なら削除)
  - Escape: キャンセル(新規ノードは削除)
- **既存ノードのリネーム**: F2 またはカードのダブルクリックでインライン編集開始。
- **EditModal は詳細編集専用に縮小**: `E` キー / 鉛筆アイコンで開き、期限・見積・優先度・カテゴリ色・ステータス・ワークログのみ扱う。テキスト入力起点としては使わない。
- store に追加するアクション: `INLINE_EDIT_START { nodeId }`, `INLINE_EDIT_COMMIT { nodeId, text }`, `INLINE_EDIT_CANCEL`。state に `inlineEditingNodeId: string | null` を追加。インライン編集中はグローバルキーボードショートカット(Tab/Enter/Space/Delete 等)を無効化する。

## 3. パン / ズーム / フォーカス

- **パン**: キャンバス空白部の左ドラッグ。ノード上の左ドラッグは従来通り reparent 用。右/中クリックパンも互換のため残す。
- **ホイール**(`use-pan-zoom.ts` 改修):
  - ホイール = 縦パン
  - Shift + ホイール = 横パン
  - Ctrl/Cmd + ホイール(トラックパッドのピンチを含む)= カーソル位置を中心にズーム
- **自動フォーカス**: 選択ノードがビューポート外(またはマージン 40px 以内)に出たら、既存の `use-tween.ts` でスムーズにパンして可視位置へ戻す。発動タイミング: 矢印キー移動、ノード追加、インライン編集開始。

## 4. ドラッグ reparent のフィードバック

- ドラッグ中、ドロップ可能なノードはホバー時にリングでハイライト。
- 不正なドロップ先(ドラッグ中ノード自身とその子孫)は opacity を下げて視覚的に無効化。
- ドロップ確定後、新レイアウト座標へ tween アニメーションで遷移。

## 5. テスト

- `layout/tree.ts` は純関数としてユニットテスト(重なりなし、親の垂直中央配置、collapsed の除外)。
- インライン編集・折りたたみ・キーボード無効化は `integration.test.tsx` の既存パターンで追加。
- 放射状レイアウト前提の既存テストは横ツリー前提に書き換え、`radial.ts` とそのテストは削除。

## 対象外(Phase 2 以降)

- ツールバー / ビュー切替 / サイドバーの再設計
- kanban / gantt / text ビューの改修
- DSL・永続化(IndexedDB)スキーマの変更(`collapsed` の追加保存のみ行う)
